# Issues

Cada spec tem uma série, que dá nome às issues (`S1-01`, `S1-02`…) e aos códigos de
rastreio (`CA-S1-01`, `SUP-S1-01`, `PER-S1-01`). Issues concluídas vão para a pasta da
série; descartadas vão para `descartadas/`.

As issues anteriores a este README (pastas `concluidos/` e `descartadas/`) nasceram antes
do esquema de séries e ficam como estão.

| Série | Spec | Pasta de concluídas |
|---|---|---|
| S1 | `spec-operacao-comercial.md` — Operação comercial mínima (papéis, responsável, motivo de perda, anexos, retorno de lead, visões salvas) | `issues/concluidas_S1/` |
